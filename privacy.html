Privacy Policy

Lester Way Backup is a private tool used only by its owner. It is not offered to the public.

  • It uses Google's drive.file permission, so it can see and change only the files it has created itself. It cannot read anything else in the Google Drive.
  • The files it uploads are encrypted before they leave the server, so Google stores them only in encrypted form.
  • It collects no personal information, shares nothing with anyone, and uses no advertising or tracking.
  • Access can be withdrawn at any time from the Google Account's security settings, under third-party connections.
